## ✨ قابلیت‌ها / Features

- **🎬 پیش‌نمایش شناور ویدیو و تصویر کنار موس (Smart Adaptive Hover Preview):**
  - **تشخیص خودکار ابعاد عمودی / افقی / مربعی:** عکس‌ها و ویدیوهای عمودی (مثل عکس‌های گوشی با EXIF و Reels) در پنجره عمودی، و فایل‌های افقی در پنجره افقی نمایش داده می‌شوند.
  - **ثابت و بدون لرزش:** تا زمانی که موس داخل محدوده همان فایل است، پیش‌نمایش ثابت می‌ماند و با خروج از محدوده فایل بسته می‌شود.
  - پخش روان با موتور **LibVLC** در ترد پس‌زمینه (بدون تیک و فریز) و مرور هوشمند ویدیو.
- **🔄 منوی دایره‌ای هوشمند مشابه Filee (هم با شورتکات و هم با `Ctrl + Drag`):**
  - **شورتکات قابل شخصی‌سازی (پیش‌فرض `Alt + Q`):** کافی است فایل یا پوشه‌ای را انتخاب کنید (یا موس را رویش ببرید) و کلید میانبر را بزنید تا منوی دایره‌ای دقیقاً کنار موس باز شود و با یک کلیک تبدیل یا پردازش انجام شود.
  - **انیمیشن‌های روان Filee:** شکوفایی تدریجی ۵ دایره، چرخش سکه‌ای دو مرحله‌ای با `Tab` یا اسکرول موس (بدون چرخش ناخواسته خودکار) و **حلقه پیشرفت زنده (Live Progress Ring)**.
- **📖 راهنمای شروع سریع تعاملی:** آزمایش زنده منوی دایره‌ای و نصب یک‌کلیکه FFmpeg در اولین اجرا.
- **🧺 قفسه موقت شناور (Drop Shelf):** جمع‌آوری فایل‌ها و پوشه‌ها از مسیرهای مختلف و انتقال یا ZIP یکجا.
- **🗂 مرتب‌سازی هوشمند پوشه‌ها + خودکارسازی Downloads:** دسته‌بندی بر اساس نوع/تاریخ با پیش‌نمایش و دکمه **بازگردانی (Undo)**.
- **✏️ تغییر نام گروهی پیشرفته (Batch Rename):** پیش‌نمایش زنده، Regex، مرتب‌سازی طبیعی، جلوگیری از تداخل و بازگردانی.
- **♻️ یافتن فایل‌های تکراری (Duplicate Finder):** اسکن ۳ مرحله‌ای فوق‌سریع (اندازه ← هش جزئی ← SHA-256) با انتقال امن به Recycle Bin.

## 🎨 تم‌های شیشه‌ای و شخصی‌سازی (Windows 11)

در تب **⚙️ تنظیمات ← ظاهر و تم‌های شیشه‌ای** چهار تم قابل انتخاب است:
**فیروزه شب، لاجورد، زمرد و آمتیست**. می‌توانید رنگ تأکیدی را با کد HEX تعیین کنید،
شفافیت کارت‌های لایه‌ای را تغییر دهید، جلوه‌ها را برای رایانه‌های ضعیف‌تر خاموش کنید
و ظاهر را به حالت اولیه برگردانید. تغییرات **زنده** و در
`%LocalAppData%\Shamsa\settings.json` ذخیره می‌شوند.

> لایه‌های شیشه‌ای با قلم‌موهای سبک WPF ترسیم می‌شوند؛ برای جلوگیری از مصرف زیاد GPU، تاری سراسری روی پنجره اعمال نشده است.

## 📁 پیش‌نمایش اسلایدی پوشه در Explorer

هنگام مکث روی یک پوشه محلی در Explorer یا دسکتاپ، کارت شیشه‌ای جمع‌وجور
باز می‌شود. شمسا حداکثر **۱۰۰ مورد سطح اول** پوشه را بررسی می‌کند
و حداکثر **۶ بندانگشتی تصویر یا ویدیو** را به صورت نمایش اسلایدی نشان می‌دهد.
**ویدیو پخش نمی‌شود**؛ برای مصرف پایین CPU فقط بندانگشتی ویدیو خوانده می‌شود.
فایل‌ها اجرا یا جابه‌جا نمی‌شوند، زیرپوشه‌ها اسکن نمی‌شوند و
پوشه‌های شبکه‌ای و فایل‌های ابری آفلاین برای پیشگیری از دانلود ناخواسته کنار گذاشته می‌شوند.
فعال/غیرفعال کردن: **تنظیمات ← پیش‌نمایش کنار موس**.

## 🔄 به‌روزرسانی خودکار امن

شمسا به‌صورت پیش‌فرض نسخه جدید را در شروع و هر ۶ ساعت بررسی می‌کند.
از تنظیمات می‌توانید **دانلود خودکار فایل نصب** را نیز فعال کنید؛
هیچ به‌روزرسانی **بدون تأیید کاربر نصب نمی‌شود**.
از GitHub Releases رسمی دانلود شده و فایل EXE با SHA-256 منتشرشده
در همان Release تطبیق داده می‌شود. پس از دانلود، نصب‌کننده اجرا و برنامه بسته می‌شود.
این کار نیازمند اتصال اینترنت است و **امضای کد Authenticode** هنوز ارائه نشده است.

## 💻 نصب روی رایانه‌های دیگر

- نسخهٔ x64 ویندوز ۱۰/۱۱، به‌صورت خودکفا همراه با **.NET Desktop Runtime** منتشر می‌شود.
- **LibVLC** همراه خروجی برنامه بسته‌بندی می‌شود؛ نیازی به نصب جداگانه VLC نیست.
- **FFmpeg** فقط برای قابلیت‌های تبدیل فایل لازم است و از راهنمای شروع یا بخش تنظیمات
  با دکمه «دانلود و نصب خودکار FFmpeg» جداگانه دریافت می‌شود.
- برنامه بدون دسترسی مدیریت سیستم در پروفایل همان کاربر نصب می‌شود.
- فایل نصب دیجیتالی امضا نشده است و ممکن است SmartScreen هشدار بدهد.
- در سیستم‌های بدون اینترنت، عملکردهای اصلی بدون دانلود اضافه اجرا می‌شوند؛
  تبدیل‌های وابسته به FFmpeg تا نصب ابزار اختیاری در دسترس نیستند.

## ⬇️ نصب مستقیم Windows 11 x64

**[دریافت آخرین نسخه در GitHub Releases](https://github.com/seyedebrahim0211-oss/Shamsa/releases/latest)**

فایل `Shamsa-Setup-v2.9.2-win-x64.exe` را اجرا کنید. نسخه نصبی
خودکفا (self-contained) است و نیاز به نصب جداگانه .NET ندارد.
FFmpeg برای قابلیت تبدیل درصورت نیاز با دکمه داخل اپ دانلود و نصب می‌شود.
فایل‌ها در مسیر پروفایل کاربر نصب می‌شوند و حذف نصب از Settings ویندوز امکان‌پذیر است.

> نصب‌کننده هنوز امضای دیجیتال کد ندارد. نام فایل و SHA-256 را از Release رسمی بررسی کنید.

## 🚀 اجرا و ساخت (Quick Start)

```powershell
dotnet restore
dotnet run
```

### ساخت نسخه پرتابل ویندوز (Publish)
```powershell
dotnet publish Shamsa.csproj -c Release -r win-x64 --self-contained true -o ./publish
```

### انتشار خودکار روی گیت‌هاب (GitHub Releases)
```powershell
git push origin main
```
