# آزمون پذیرش نسخه ۳.۳.۰

آزمون خودکار CI: ساخت Release، آزمون‌های رگرسیون ایوان، بررسی وابستگی‌های NuGet و تولید هش نصب‌کننده. موارد زیر فقط با ویندوز واقعی و سخت‌افزار متصل قابل تأیید هستند؛ موفقیت CI جایگزین این آزمون‌ها نیست.

- [ ] دو نمایشگر با DPI متفاوت، انتخاب هر تم، تغییر مانیتور اصلی، قطع و وصل مانیتور دوم؛ ویجت‌ها و داک روی نمایشگر اصلی باقی بمانند و تسک‌بار دوم دست‌نخورده باشد.
- [ ] تطبیق برنامه‌های پین‌شده کلاسیک و برنامه‌های فروشگاه ویندوز و پنجره‌های باز؛ خروج و بازگردانی تسک‌بار.
- [ ] نصب افزونه ایوان و تطبیق شهر، منطقه زمانی، اذان بعدی، آب‌وهوا؛ قطع اتصال و بازگشت به شهر دستی.
- [ ] ضبط ۳۰ و ۶۰ فریم، صدای سیستم، رنگ کلیک، وب‌کم داخلی و USB، هر چهار گوشه؛ مکث و ادامه.
- [ ] فرمان فارسی آفلاین، رهاکردن دکمه، خروج از صفحه، تغییر فوکوس و سقف ۳۰ ثانیه؛ کنترل نشانگر میکروفون ویندوز.
- [ ] تعویض میانبرها، تداخل، بازنشانی و حفظ پس از راه‌اندازی مجدد.
- [ ] نصب روی ۳.۲.۰ بدون حذف داده و تنظیمات؛ بررسی به‌روزرسانی داخل برنامه و تطابق SHA-256.
- [ ] اسکن نصب‌کننده و امضای Authenticode (نیاز به گواهی معتبر ناشر).
